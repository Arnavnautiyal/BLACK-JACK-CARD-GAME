# Command-Line Blackjack in Python

A clean, interactive console-based implementation of Blackjack featuring dynamic Ace handling, automated dealer AI, and persistent bankroll/bet management.

## Features
- **Full Rules Logic**: Handles Blackjack states on deal, player busts, dealer draws, and tie settlements.
- **Dynamic Ace Calculation**: Automatically shifts Aces from 11 to 1 to prevent busting.
- **Credit & Betting Loop**: Track your bankroll across multiple rounds with session persistence.

## Getting Started

### Prerequisites
- Python 3.8 or higher installed on your machine.

### Running the Game
Clone the repository and run the main script from your terminal:

```bash
git clone https://github.com/your-username/blackjack-python.git
cd blackjack-python
